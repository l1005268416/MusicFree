# 元力KG 插件播放修复

## 问题原因

插件本身没有坏，搜索也正常；问题出在**播放取链所用的第三方接口已下线**。

原插件的 `getMediaSource` 固定请求：

```
https://music-api2.cenguigui.cn/?kg&id=<hash>&type=song&level=<level>
```

实测该服务已经无法连接（域名/TLS 直接失败，作者博客也返回 Cloudflare 521），所以表现就是：

- 搜索：走 `songsearch.kugou.com`，正常；
- 播放：走 `music-api2.cenguigui.cn`，拿不到 URL，播放失败。

## 修复内容

`元力KG.fixed.js` = 原插件文件 + 末尾追加的播放补丁（原文件是 jsjiami 混淆代码，补丁追加在文件最后，不改动原有搜索/歌词/歌单逻辑）。

补丁做了三件事：

1. **酷狗官方取链**
   使用 `trackercdn.kugou.com`，按音质选择对应 hash：
   - 低音质 → `id`（128k）
   - 标准 → `320hash`（320k）
   - 高音质 → `sqhash`（FLAC）
   - 超高音质 → `ResFileHash`（Hi-Res FLAC）
   取链失败会自动降级到下一个可用 hash。

2. **酷狗受限时自动回退酷我**
   酷狗对 VIP/付费歌曲会返回 `The Resource Needs to be Paid`。此时用
   “歌名完全一致 + 同歌手或时长相差 ±3 秒”的严格匹配，在酷我找同一首歌：
   - 优先 `music.nxinxz.com` 中转（可拿到 320k / 无损）；
   - 失败再走酷我官方 `antiserver.kuwo.cn` 接口。
   匹配不到就返回空，不会随便播放翻唱/现场版。

3. 版本号改为 `0.1.1`，避免被旧版（`0.1.0`）当成低版本覆盖。

## 安装方法

### 方式 A：本地安装（推荐）

1. 如果已经装了旧的「元力KG」，先在插件设置里卸载它；
2. 插件设置 → 右下角 `+` / 从本地安装；
3. 选择 `元力KG.fixed.js`。

### 方式 B：替换服务器文件

如果你能修改 `jia.liufly.top:20001` 上的文件：

1. 用 `元力KG.fixed.js` 覆盖原文件
   `http://jia.liufly.top:20001/music/2d67f88f71ca165c29cb8994efe3c262.js`
2. 在 MusicFree 里重新安装该插件地址（或重启 App）。

> 文件里的 `srcUrl` 仍然指向原地址，直接覆盖即可，不需要改其它内容。

## 验证结果

本机已用插件真实跑通：

- 免费歌曲（如《稻香 (童声版)》）：酷狗官方直链，128k / 320k / FLAC / Hi-Res 均返回 `audio/*`；
- 周杰伦等 VIP 歌曲（《晴天》《平凡之路》《起风了》）：自动回退酷我，320k / FLAC 可正常播放；
- 歌词仍走原插件的酷狗歌词接口，不受影响。

## 限制说明

- 酷狗官方接口对 VIP/付费歌曲确实没有播放权限，这是平台限制，不是插件 bug；
- 酷我回退依赖公开接口，如果以后该接口也失效，把补丁里的 `getKuwoUrl` 整段删掉即可，至少免费酷狗歌曲仍然能播；
- 播放链接有时效性，重播时会重新取链，属正常现象。

## 文件说明

- `元力KG.fixed.js`：可直接安装的完整插件；
- `元力KG.patch.js`：补丁源码（方便查看/修改/再次追加到新版插件）。
